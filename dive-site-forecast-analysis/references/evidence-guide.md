# 潛點預報證據指南

在收集、篩選與解讀 forecast 證據時讀取本文件。

## 記錄每個來源

至少記錄：

```text
source_name
source_url
product_or_model
issued_or_initialized_at
valid_from
valid_to
retrieved_at
spatial_resolution
location_or_grid_point
distance_to_site
units
quality_or_model_notes
```

不要用網頁載入時間取代預報發布／初始化時間，也不要混用 UTC 與潛點當地時間。

## 排定來源優先順序

1. 官方封閉、警特報、海岸／海域警示與管理單位公告。
2. 官方氣象、海洋、潮汐、河川與水文機構的預報和觀測。
3. 說明模型、解析度、初始化時間與驗證方法的高解析產品。
4. 港口、國家公園、潛點管理單位及在地長期資料。
5. 時間與位置明確的潛店、潛導、船長或潛水社群資訊。
6. 商業聚合平台與一般貼文，作為補充而非唯一安全依據。

來源衝突時，優先考慮資料時效、空間代表性、方法透明度、近期觀測偏差與問題類型，不只看品牌。

## 收集關鍵變數

### 波浪與湧浪

- 有效波高、可能最大浪、主／平均週期、主波向。
- 湧浪高度、週期、方向及多組湧浪。
- 風浪與湧浪是否來自不同方向。
- 長浪、異常浪、熱帶系統或遠方低壓影響。
- 相對潛點海岸方向及入水口的夾角。

低浪高不代表低風險；長週期且直入岸口的浪可能產生較強碎波、浪組與 Surge。

### 風

- 平均風、陣風、風向、轉向時間、近岸與外海差異及海陸風循環。
- 向岸風可能增加近岸風浪；離岸風可能增加漂離岸邊與水面支援風險；沿岸風可能強化沿岸流。
- 地形遮蔽可能減弱局地風，但不會自動阻擋外海湧浪。

### 潮位與海流

- 潮位曲線、滿／乾潮、潮差、漲退潮區段與變化速率。
- 表層流速／流向、潮流、風生流、區域環流與可得的不同深度流。
- 潮位極值與流速極小值可能不同步。
- 區域模式可能無法解析礁岩、岬角、狹窄水道、下降流或垂直流。
- 將流向轉成相對於岸邊、岬角、航道與回收區的意義。

### 降雨、河川與能見度

- 潛點與上游集水區的預報降雨。
- 前 24／48／72 小時實際累積雨量。
- 河川流量／水位／濁度、河口與排水口、洩洪或施工事件。
- 衛星水色、懸浮物、葉綠素、Secchi 深度及近期現場回報。
- 波浪擾動、底質、潮向與濁水輸送延遲。

當日無雨不等於水清。雲遮、淺水海底反射與不同區域算法會限制衛星水色；不要直接換算成固定水下能見度。

### 其他危害

- 雷雨／雷擊、強風、大雨、熱帶氣旋、季風、霧與水平可見度。
- 水溫與可能的溫躍層或冷水突降，但不要僅由海表溫度斷言水下溫度。
- 航道、船隻、漁網、港口作業、救援與撤離限制。

## 建立潛點暴露模型

至少判斷：

- 海岸與入水口朝向。
- 哪些波向／風向會直入、沿岸或離岸。
- 灣澳、島嶼、岬角、礁台與水道的遮蔽或聚焦。
- 入水區與主潛區是否具有不同暴露方向。
- 海岸坡度、岸邊材質、底質及低潮暴露。
- 河口、排水口、航道與替代出水點。

把區域預報經此模型轉譯為潛點影響；若缺少地形資訊，明示只能做區域級判讀。

## 依時效調整解析度

| 預報距離 | 建議表達 |
|---|---|
| 0–24 小時 | 逐時或每三小時；仍需最新 nowcast 驗證 |
| 24–72 小時 | 比較具體時窗，列出模型一致性與轉折 |
| 第 4–5 天 | 以半日／日趨勢為主，不給精確進出水承諾 |
| 第 6–7 天 | 只排名相對趨勢、主要風險與重新確認時間 |

若模式在風向、系統路徑或湧浪到達時間上分歧，縮短可承諾的時間窗並降低信賴度。

## 辨識停止條件

優先排除：

- 官方封閉或警示。
- 雷雨、強風、熱帶系統或明顯長浪威脅。
- 入水／出水口在目標時段可能明顯高風險。
- 流向外海、航道、岬角外側或不可回收區。
- 條件在預計出水前快速惡化。
- 關鍵來源嚴重衝突且無法建立合理安全判斷。
- 團隊缺少所需船隻回收、放流程序或救援能力。

## 比較多個時段

依序比較：

1. 停止條件與安全危害。
2. 入水及出水條件。
3. 水下流與漂流後果。
4. 雷雨、風與天氣穩定性。
5. 能見度趨勢。
6. 預報信賴度與資料缺口。

不要只產生加權總分。某時段即使總分較高，單一不可接受的進出水或流向仍應淘汰。

## 評估信賴度

| 等級 | 判準 |
|---|---|
| 高 | 短時效、多個近期來源一致、模式初始狀態貼近觀測，且潛點暴露關係明確 |
| 中 | 主要資料完整，但缺少局部流／入水口資訊，或來源有可解釋的小幅分歧 |
| 低 | 遠期、模式分歧、快速變化、空間解析度不足或關鍵資料缺失 |

信賴度高不等於風險低；它只表示對預報判斷較有把握。
